## Installation

### Requirements
- Rust and Cargo installed.

### Install

Clone the repository:

```bash
git clone https://github.com/LosChickenMan/stock-price-ascii.git
cd stock-price-ascii
```

Run the installer:

```bash
./install.sh
```

Launch Stonks from anywhere:

```bash
stonks
```

**Note:** Make sure `~/.local/bin` is included in your PATH.
